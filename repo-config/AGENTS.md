# AGENTS.md — 写作与质量公约

## 全局铁律（回复 / 文档 / 注释 / PR 描述一律适用）

1. **读者模型**：假设读者有基础代码知识 + 前序需求知识，但没有本次内容的任何先验知识。
2. **结论先行**：先给结论/总览，再展开。
3. **零跳跃**：每一步自然延伸，读者不需脑补任何中间步骤。
4. **术语唯一**：一词一义；术语来自「当前项目 openwiki 术语表」（六列：中文术语 / English / 代码真实命名 / 定义 / 别名禁用词 / 出处）；查不到标 `[待定]`，严禁自造词。
5. **通俗言简**：参照受欢迎的技术博客——通俗易懂、言简意赅。
6. **极简**：凡读者不需要、或徒增认知负担的文字，一律删去。

## 进入写作前（强制，只用于写文档）

写任何文档（design / spec / 分析 / 汇报 / wiki 等），不论用哪个 skill：

0. **必须先 read 详细规范** `quality-writing/methodology/writing-methodology.md` —— A1–A5（拆解）、B1–B4（展开）、五问（自检）都在里面；不读不往下走。
1. **阶段一思考**：按 A1–A5 拆解，或用思考类 skill（brainstorming / openspec-explore / grill-me）辅助——它们同属阶段一。
2. **固化成脑图**，停下等我确认；不确认，不进入阶段二。
3. **阶段二展开**正文，写完过「通用五问」。

## 评审既有文档时

用「通用五问」逐条检查，列出需要脑补/跳跃的点，给出修改建议。
